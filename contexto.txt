2. ANATOMÍA Y ESTRUCTURA DE CADA LIBRO EXCEL (RD.402.P.01.F.01)
================================================================================
Dentro de cada archivo `RD.402.P.01.F.01*.xlsx`:
- Hay múltiples pestañas. Cada pestaña con nombre de máquina (ej. `XRD50U-002`, `LM90U-001`) contiene los datos de perforación de esa máquina.
- Pestañas administrativas que NO deben procesarse: `ADITIVOS`, `GENERAL`, `LISTAS`, `TIEMPOS`, `Tiempos`, `RESUMEN`, `GRAFICOS`, `MAESTRO`, `PARAMETROS`, `GLOSARIO` y cualquier hoja oculta.
- Estructura vertical de cada pestaña operativa:
  * Filas 1 a 22: Encabezado administrativo (logos, cliente, datos generales).
  * Fila 23 (Índice 22 de base 0): Nivel 1 de encabezados con celdas combinadas por grupos (ej. "BENTONITA", "HOROMETRO", "RIMADO CON CASING", "BITACORA DE MANTENIMIENTO").
  * Fila 24 (Índice 23 de base 0): Nivel 2 de encabezados con subtítulos (ej. "PRODUCTO", "CANT.", "UND.", "DESDE", "HASTA", "METRAJE", "TOTAL", "TRABAJOS REALIZADOS", "REPUESTOS UTILIZADOS").
  * Fila 25 (Índice 24 de base 0): Primera fila de datos de guardias operativas.
  * Filas posteriores: Filas de guardias diarias (Turno Día / Turno Noche).
  * Filas finales: Celdas con sumatorias o texto de pie de página como `TOTAL`, `TOTAL GENERAL`, `RESUMEN`, `PROMEDIO`, `SUMA`, `TOTAL AVANCE` o que comiencen con `>` (deben filtrarse y descartarse).

4. REGLAS DE NEGOCIO Y DESAFÍOS TÉCNICOS
================================================================================
1. Celdas combinadas en Fecha (Col A): Solo la primera guardia del día tiene fecha digitada. Las filas siguientes del mismo día quedan vacías y requieren FillDown.
2. Celdas combinadas en Sondaje (Col B): Requieren FillDown y FillUp para no perder la asignación del taladro.
3. Desafíos de Power Query M que suelen provocar errores:
   - Invocar `Excel.Workbook([Content])` de forma anidada dentro de cada fila genera error de `Formula.Firewall` (Niveles de Privacidad) o agota la memoria de descompresión.
   - Si las cabeceras se construyen combinando texto dinámico entre filas 23 y 24, pequeñas variaciones entre contratos rompen `Table.Combine` y multiplican las columnas con nulos.
   - Solución requerida en M: Abrir `Excel.Workbook([Content])` una sola vez en la consulta padre, pasar la tabla `[Data]` a una función `fn_ProcesarHojaDetallado`, seleccionar posicionalmente las primeras 168 columnas (`Column1` a `Column168`) y renombrarlas en bloque al catálogo canónico para que todas las hojas tengan un esquema 100% idéntico y seguro.
4. Metadatos obligatorios a incluir en la tabla final: `CTR` (extraído del nombre de la carpeta), `MAQUINA` (nombre de la hoja), `TURNO_ESTANDAR` (A o B) y clave `ID_CLAVE_UNICA` (`YYYYMMDD-MAQUINA-TURNO`).
