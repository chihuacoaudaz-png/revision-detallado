# 📦 Baúl de Desuso y Archivo Histórico (Legacy Archive)

Este directorio almacena de forma ordenada y segura todos los archivos temporales, versiones legacy, guías previas y copias redundantes de etapas iniciales del proyecto. **Ningún dato ha sido eliminado**, preservando el 100% de la trazabilidad histórica sin saturar el espacio de trabajo activo.

---

## 📁 Estructura del Baúl:

1. **`archivos_raiz_temporales/`**:
   * Scripts y notas de contexto creados durante las sesiones de prueba iniciales (`contexto.md`, `contexto.txt`, `PARAMETROS_EJECUCION_CASA.txt`, `PROMPT_INICIAL_AGENTE_CASA.md`, `TEST_INFRA.md`, `TEST_READY.md`, etc.).
2. **`historicos_pesados/`**:
   * Libros maestros pesados de etapas preliminares (`HISTORICO-PERDLAP140.xlsx`).
3. **`copias_detallados_antiguas/`**:
   * Carpetas con copias intermedias de archivos detallados (`data_in/`, `distribucion/`, `NUEVO FORMATO DETALLADO/`), sustituidas por la conexión directa a SharePoint Cloud (`Estructura base/` y Power Query).
4. **`contexto_y_guias_previas/`**:
   * Guías rápidas y diagnósticos tempranos (`contexto/`, `guia/`).
